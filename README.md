# 低ナトリウム血症 補正シミュレーター

食事・輸液・尿出納から血清Na値の **24時間推移を予測**するブラウザアプリ。ビルド不要・オフライン動作（外部CDNに依存しない）。

## 使い方
`index.html` をダブルクリックしてブラウザで開くだけ。フォルダごと（`index.html` / `css/` / `js/`）コピーすれば別PCでも動作する。

## 入力項目と単位
| 項目 | 単位 | 備考 |
|---|---|---|
| 現在の血清Na | mEq/L | |
| 体重・係数 | kg / – | TBW = 体重 × 係数（男0.6 / 女・高齢男0.5 / 高齢女0.45） |
| 食事由来 **食塩相当量** | g/日 | **NaCl 1 g ≈ 17 mEq Na** で換算（摂取率を乗算） |
| 内服NaCl | g/日 | NaCl錠等の経口食塩。×17換算、**摂取率は乗じない**（薬剤＝確実投与） |
| 食事由来K | g/日（元素K） | **K 1 g ≈ 25.6 mEq** で換算 |
| 食事水分・飲水・代謝水 | mL/日 | 代謝水は体重×5 を自動計算（手動切替可） |
| 食事摂取率 | % | 食事Na・K・水分に乗算 |
| 輸液 Na/K 濃度・投与量 | mEq/L・mL/日 | 複数登録可 |
| 尿Na・尿K 濃度 | mEq/L | |
| 尿量・不感蒸泄 | mL/hr | 不感蒸泄は体重×15÷24 を自動計算（手動切替可） |

> 旧バージョンは「食事由来Na (g)」と表記しつつ実際は食塩相当量（×17）で計算していたため、ラベルを **食塩相当量** に修正した。

## 計算モデル
Edelman式 `[Na] = (総Na + 総K) / TBW` を **1時間ステップで24回逐次更新**（Euler積分）する。

```
初期: TBW = 体重×係数, 総Na+K = Na₀×TBW, 総水分 = TBW
毎時: 総Na+K += (IN_NaK − OUT_NaK)/h
      総水分  += (IN_水 − OUT_水)/h
      Na(t)   = 総Na+K / 総水分
```

- IN：食事Na+K、内服NaCl、飲水・食事水分・代謝水、各輸液
- OUT：尿（Na+K、水分）、不感蒸泄（自由水）
- 旧バージョンの「初期速度を24倍する線形外挿」を廃止。逐次計算により補正進行に伴う速度変化を反映する。

### 仮定と限界
- **尿Na/K濃度・尿量は予測期間中一定**と仮定（補正に伴うADH・尿濃縮の変化は未反映）。
- 発汗・消化管喪失などは考慮していない（必要なら不感蒸泄・尿量で近似入力）。
- あくまで出納の概算であり、実測のフォローアップに代わるものではない。

## 安全評価
24時間の総補正幅で層別判定する。

| 区分 | 標準 | ODS高リスク* |
|---|---|---|
| 目標上限 | ≤ 8 mEq/L/24h | ≤ 6 mEq/L/24h |
| 危険域 | > 10 | > 8 |

\* Na ≤ 105・低K血症・アルコール依存・進行肝疾患/低栄養 のいずれか該当でリスク因子をONにすると厳格化。
過小補正（ほとんど補正されない／低下方向）も警告表示する。グラフ上に目標域（緑）・上限超（黄）・危険域（赤）を帯表示。
